安全说明

          

            
    
              
  • 面板首次启动必须完成初始化（设置管理员密码），之后所有 API 均需登录；密码以 PBKDF2-HMAC-SHA256（10 万轮加盐）存储在 <run-dir>/dashboard_auth.json，任何接口都不输出它。
    • 
              
  • 登录签发的会话 Cookie 为 HttpOnly + SameSite=Strict（12 小时过期，可点左下角「注销」失效）；登录按 IP 限流（5 分钟 5 次失败锁定 60 秒）；Cookie 会话的写操作必须带防跨站请求头。
    • 
              
  • 无头/CI 场景可用 DASHBOARD_TOKEN 作为 Bearer 凭证（对全部 API 有效），设置后可跳过初始化向导。
    • 
              
  • 面板默认仅监听 127.0.0.1；如需远程访问请置于带 TLS 的反向代理之后。
    • 
              
  • 写操作（服务控制 / 签发 / 撤销 / 解绑 / 配置编辑 / 方案切换）默认即为管理模式；如需只读展示，启动时加 -read-only。
    • 
              
  • 面板本身不接触密钥原文：密钥由 fwknopd-admin 生成；access.conf 的密钥行在界面与 API 中一律掩码，stanza 在线编辑只允许修改非密钥指令。
    • 
              
  • 启动服务前强制配置预检（--exit-parse-config）；任何配置落盘都会先预检、自动备份（.bak-时间戳）并热加载（SIGHUP）。
    • 
              
  • 方案切换会先校验方案配置，再备份当前配置——可随时回滚。
    • 
              
  • 撤销用户会将对应 stanza 注释禁用（可在「用户与授权」页一键恢复）；SPA 协议版本 4.0.0，与 v3 客户端向后兼容。
    •
