# 2.4.2（2026-08-23）—— WebUI 体验深化

2.4.1 之后按「持续 UX 优化」循环完成的约 60 项迭代汇总（每轮独立 commit，见 git 历史）。

## 签发（用户页）
- 全字段即时校验：名称（格式 + 唯一性）、服务器地址（IPv4/IPv6/主机名 + 历史下拉）、OPEN_PORTS、TOTP 端口范围、TOFU 宽限期（范围 1-8388608 秒，与服务端 RCHK_MAX_FW_TIMEOUT 对齐，天数换算提示）
- 提交前全字段汇总拦截，聚焦第一个非法字段（校验规则抽为纯函数 `V.*` 单点维护）
- 模板：hover/聚焦预览描述（不填充）；填充后派发 input 事件联动校验提示；模板选择状态随草稿持久化
- 草稿恢复改内联提示条 + 一键清空；成功 toast 带凭证名；结果区滚动定位 + 闪烁 + 自动聚焦「复制 URI」（键盘流闭环）
- 空态直达签发按钮（防重复展开）

## SPA 事件页
- 行点击/Enter/空格展开全部审计字段（时间戳可复制、完整指纹、原始+中文原因、三维反查按钮、复制原始 JSON），键盘可达（tabindex/aria-expanded）
- 异常行淡红底色（详情行成组）；异常占比可视化条；放行/拦截率语义着色
- 新事件到达提示条（非第一页/带筛选时）；端口列点击筛选，搜索匹配扩展到端口字段
- 时间列点击切换相对/绝对（偏好持久化）；←/→ 翻页快捷键；空筛选一键重置
- 导出当前筛选结果为 CSV（BOM + 转义 + 时间戳文件名），按钮实时标注匹配条数

## TOFU
- 批量解绑（勾选 + 全选三态 + 操作条 + 结果汇总）
- 用户卡片绑定数徽章（stanza_key 与服务端 tofu_stanza_key 规则一致）直达绑定列表；TOFU 表用户名反查事件
- 解绑成功提示带自动重绑/白名单路径指引；空态检测近期 unknown_fingerprint 拒绝并给排查入口
- 来源/端口列点击复制（提示语按列区分）

## 配置与方案
- 编辑器行级修改高亮（琥珀=已改 / 绿=新增，保存后重置基线）
- 指令值类型校验红框（端口/端口范围/超时类）；保存前拦截非法值并聚焦
- 修复：有值无键的行原先被静默丢弃，现保存前拦截
- 配置分组可折叠（状态持久化）；Ctrl/⌘+S 快捷保存
- 方案应用确认内嵌与当前配置的 diff；方案名查重（输入预警 + 覆盖红色确认）

## 概览与全局
- 计数变动脉冲动画；指标生成时间 >5 分钟标「陈旧」；审计体积 fmtSize + 50MB/200MB 分档警示
- 服务运行时长每秒跳动；daemon pill 点击直达服务控制；首次部署三步引导条；迷你趋势点位 hover 数值
- 通知历史面板（铃铛 + 未读徽标 + 最近 50 条，合并去重）；错误 toast 默认驻留
- 会话剩余时间显示（/api/auth/state 新增 session_exp 字段）+ <30 分钟琥珀 + <5 分钟主动 toast
- 断连重试倒计时；模态框焦点捕获（Tab 循环，破坏性确认默认聚焦取消）；移动端侧栏滑动手势；表格斑马纹；搜索框统一清空按钮
