# fwknop fork 2.2.0 —— WebUI 全面重设计 + 服务端管理闭环

> 发版日期：2026-08-23
> 上游基线：fwknop 2.6.11（客户端版本号仍为 `2.6.11`，SPA 协议 `4.0.0`）
> 计划文档：[REF/plan/Port Knocking.md](../../REF/plan/Port%20Knocking.md) §7.4/§7.6
> 本版本重设计服务端 WebUI（美观性 / UX / 完全汉化），并补全 `fwknopd-admin`
> 的占位命令，使「签发 → 列表 → 撤销 / 解绑」管理闭环在 CLI 与 WebUI 同时可用。

## 摘要

- **WebUI 重设计**（[server/dashboard/](../../server/dashboard/)）：侧边栏六页布局
  （概览 / SPA 事件 / 用户与授权 / TOFU 绑定 / 服务配置 / 关于），完全汉化，
  明暗双主题、自动刷新（可暂停）、筛选/搜索/分页、迷你趋势图、骨架屏/空状态/
  toast/二次确认等完整 UX 细节。
- **功能覆盖全方位**：面板从「指标 + 事件 + 签发」扩展为覆盖软件全生命周期——
  服务状态、授权列表（密钥掩码）、签发全选项、撤销、TOFU 结构化查看与解绑、
  服务配置分组中文解读。
- **fwknopd-admin 补全**：`user list / user rm / user qr / lint / tofu unbind`
  五个占位命令全部落地（此前只有 `user add / tofu list / status` 真实可用）。

## fwknopd-admin 新增实现

| 命令 | 行为 |
| --- | --- |
| `user list [--access-conf F]` | stanza 表格：名称/来源/用户/端口/密钥(Y/N)/HMAC/TOTP/指纹模式；密钥只显示 Y/N |
| `user rm <name>` | 注释禁用 stanza（先备份 `access.conf.bak-<ts>`，可恢复），尽力 SIGHUP 热加载 |
| `user qr <name> --server H` | 从既有 stanza 重建 `fwknop://` URI 并渲染 QR（密钥不落新文件，用后擦除） |
| `lint [access.conf]` | 一致性检查：缺密钥 / 缺 HMAC / `__CHANGEME__` 占位 / TOTP 种子与范围 / REQUIRE_TOTP_PORT_MATCH / OPEN_PORTS 格式 |
| `tofu unbind <key> <device_id>` | 从状态文件删除绑定（先备份），尽力 SIGHUP |

配套变化：`user add` 输出的 stanza 现在带 `### fwknopd-admin user: <名称>` 标记
注释，使 list/rm/qr 能按凭证名识别 stanza（rm 时该标记一并失效，不会误挂到
后续 stanza）。

## dashboard 后端（Go，零依赖）

- 新端点：`/api/overview`（进程存活探测、文件新鲜度、管理工具状态）、
  `/api/users`（access.conf 掩码解析）、`/api/config`（fwknopd.conf 指令 + 原文）、
  `/api/tofu`（结构化绑定）；写端点新增 `/api/admin/rm`、`/api/admin/tofu/unbind`，
  `user add` 包装扩展到全部选项。
- 拆分 `main.go` → `main.go`（骨架）+ `parse.go`（解析器）+ `api.go`（处理器）。
- 安全：全部响应加 nosniff / DENY / no-referrer 头；写端点统一 15s 执行超时；
  面板任何响应都不含密钥原文。

## dashboard 前端（单文件 index.html，go:embed）

- 设计：暗色默认 + 浅色切换（localStorage 记忆，遵循系统偏好），卡片式布局、
  圆角/柔和阴影/微动效（尊重 prefers-reduced-motion）、内联 SVG 图标库、
  中文排版字体栈。
- 概览：5 张状态卡 + 8 张计数 tile（前端采样差分绘制 SVG 迷你趋势）+ 汇总条。
- 事件：类型筛选 chip（带计数）、搜索、20 条/页分页、相对时间 + 悬停绝对时间。
- 用户：stanza 卡片（特性徽标：HMAC/TOTP/指纹白名单/TOFU/端口因子）；
  `__CHANGEME__` 占位授权红框告警；签发结果一次性展示 + 一键复制 URI。
- 配置：fwknopd.conf 生效指令按「网络抓包/安全策略/防火墙/NAT/审计/路径/GnuPG/
  高级」分组，约 45 个指令附中文说明；可切原文视图。
- 通用：连接状态指示、自动刷新 3/5/10/30s（页面隐藏自动暂停）、toast、
  危险操作模态确认、复制到剪贴板、移动端抽屉式侧边栏。

## 已知限制

- 面板不做 fwknopd 进程启停（systemd 集成属环境相关，刻意保持面板为「视图 +
  薄壳」）；撤销/解绑的 SIGHUP 为尽力而为，PID 文件不可读时提示手动 reload。
- 凭证 QR 重渲染（`user qr`）仅在 CLI 提供（需 root 读 access.conf），
  WebUI 不提供——凭证一次性展示原则。
- 配置页为只读展示，不支持在线编辑 fwknopd.conf（编辑配置文件建议走
  配置管理/版本控制流程）。
