# 2.4.5（2026-08-23）—— 审计备份生命周期 + 排查效率 + 安全硬化

2.4.4 归档后按「持续 UX 优化」循环完成的 27 项迭代汇总（每轮独立 commit，
`git log b53aadbb..9bc558a8` 可逐条追溯）。

## 审计日志管理闭环（新）

- **面板内一键清理**：概览审计卡新增「清理」按钮（管理模式），确认后
  服务端 rename 备份为 `.bak-时间戳` 并清空。fwknopd 每次写入都是
  open(O_APPEND)/close（audit.c），不持有 fd，重命名安全。
- **备份可取回**：`/api/audit/download?bak=<文件名>` 下载备份，文件名
  正则白名单 `^fwknopd_audit\.log\.bak-\d{8}-\d{6}$` 防路径穿越；
  清理回执弹窗直接给下载按钮。
- **备份可见**：`/api/overview` 新增 `audit_backups`（数量/总字节/文件名
  列表）；审计卡三档均附「备份 ×N」，刚清空时显示「已清空 · 备份 ×N」
  避免误以为数据丢失；关于页列出全部备份逐个可下载。
- **备份可删除**：`POST /api/admin/audit/rmbak`（同一白名单校验），
  关于页逐个删除（confirmDialog 确认）。

## 签发（用户页）

- 结果区新增「下载 cred.json」：浏览器端把签发 URI 直转 JSON v1 凭证
  （转换规则逐行对照 server/credential.c，urlsafe base64 还原 + 补 =
  填充）。端到端验证：真实签发 → 转换 → `fwknop import` 成功且密钥
  逐字节一致。
- 预制模板新增「临时排障（5 分钟）」：关 TOTP/指纹、fw-timeout 300s，
  描述明确警示用后撤销。
- 名称一键时间戳命名（cred-YYYYMMDD-HHMM，重名 -2/-3）。
- 授权可按「绑定设备数」排序；修复用户页不拉取 TOFU 数据导致绑定数
  徽章缺失的问题；卡片授权名称点击复制。
- 秒值人性化：`fmtSecs` 把 86400 秒显示为「1 天」（访问超时、TOFU
  首用绑定徽章）。
