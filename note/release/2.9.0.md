# 2.9.0（2026-08-24）

WebUI 持续 UX 优化第七批归档：自 2.8.0（commit `2126a67d`）起 **80 项提交**
（功能/修复为主体，另含 658 文案审计与笔记维护等文档项）。回归套件保持
**115/115 PASS**。主题：**排障定位闭环**（预检/保存失败直达出错行、跳行
三模式）、**「所搜即所见」高亮收口**（六个列表/视图）、**配置备份可见
可回滚**、**方案导出/导入迁移闭环**（tar.gz）、**一键体检**（部署检查
清单聚合）、**进程级日志面板内出口**、**签发连续作业打磨**。

Go 端新增端点（均走既有鉴权/写门禁模型）：`/api/profiles/export`、
`/api/profiles/import`、`/api/service/log`、`/api/config/bakview`。

## 排障定位闭环（错误直达出错行）

- **预检失败按错误文件分流**（01b70887）：错误落在 fwknopd.conf 则原文
  编辑模式锚定出错行；落在 access.conf 则打开原文查看器跳行定位。
- **保存失败定位**（dc863b4a/5d9b6421）：原文编辑模式补「定位第 N 行」
  （textarea 即预检 payload，行号严格对应）；结构化模式按出错行内容
  提取指令名 + 「在编辑器中过滤」——不依赖易误导的行号。
- **access.conf 查看器跳行三模式**（bf2c39aa/abb583c6）：行号 / 授权名 /
  #序号；lint 定位按钮自动带入首条 ERROR/WARN；修正 stanza 标记匹配为
  真实格式「### fwknopd-admin user:」（78bf196b）；跳行框补 Enter 显式
  触发（6a3505fd）；授权卡/禁用块行号标注点击直达原文（cebcc316）。
