# 2.6.0（2026-08-23）

WebUI 持续 UX 优化第四批归档：自 2.5.0（commit `cbf53027`）起 44 项提交
（43 项功能/体验迭代 + 1 项测试基建：-version 用例改次版本号通配，归档升版
不再挂测试，36c86a47）。回归套件从 112 升至 115 PASS（新增 3 个「重发 URI」
端点用例）。主题：弱网与宕机可靠性加固、授权生命周期闭环（重发 URI）、
可访问性第二批、编辑器校验对称性、时间呈现对时化。

## 弱网与宕机可靠性加固

- fetch 统一超时：GET 12s / 写操作 20s（AbortController）——服务器 hang 时
  轮询不再永远 pending，断连指示/退避/刷新钮旋停全部恢复生效（856e55e9）。
- 断连轮询指数退避：`ivl×2^n` 封顶 60s，宕机期间不再按原间隔打无效请求，
  倒计时显示真实重试时刻，手动刷新立即清退避（cc0ec4e0）。
- 浏览器离线事件即刻置断连指示、上线即刻刷新，不等轮询周期（08409bd9）。
- 启动自检失败自动重试（5 秒倒数）+ 手动立即重试按钮，面板恢复免 F5（690d2902）。
- 写操作网络层失败统一兜底：连接拒绝/超时翻译为中文 toast，10 处静默 catch
  不再「点了没反应」；HTTP/401/403/429 分支排除防双弹，批量场景靠既有
  toast ×N 合并防刷屏（fc898e14）。
- unhandledrejection 全局兜底：async 链路漏接 catch 的异常以驻留 toast 暴露；
  api() 错误打 apiHandled 标记防双弹（dd077550）。
- localStorage 写入统一经 lsSet/lsDel 安全助手，隐私模式/配额满不再中断
  事件处理器（19 处收口，7bc51bd8）。

## 授权生命周期闭环：重发 URI

- 新端点 `POST /api/admin/qr`：为已有授权重建 fwknop:// 授权 URI（包装
  `fwknopd-admin user qr`）。access.conf 不记录服务器地址故须随请求提供；
  与签发同级写权限 + CSRF；密钥材料不离开服务器（2bde6186）。
- 用户卡「重发 URI」两步弹窗：第一步补录服务器地址（历史 datalist 点选 +
  上次地址预填 + 实时校验 + Enter 提交）；第二步展示 URI——key/hmac/totp
  参数级掩码防窥屏，复制 URI/导入命令/下载 cred.json 均不受掩码影响（26333cc1）。

## 可访问性第二批

- 「跳到主内容」skip link：键盘/读屏用户首站 Tab 直达主区，免穿侧栏十余个
  聚焦站（4ceab539）。
- 鉴权错误框 role=alert、14 处实时校验提示 aria-live=polite：读屏用户可感知
  登录失败与表单校验反馈（ed961ed8）。
- 折叠/切换控件 aria 状态补全：侧栏汉堡/窄栏/原文/安全区/分组/禁用区（a6281fbe）。
- 表单标签 for/id 关联：读屏可朗读、点标签聚焦（f0920c80）。
- JS 平滑滚动统一走 SB()：尊重系统「减弱动效」偏好，CSS 媒体查询管不到的
  scrollTo/scrollIntoView 不再晃前庭敏感用户（13 处收口，e8dc92ac）。
- Esc 链两路扩展：接入移动端侧栏收栏（与遮罩/手势/切页同效，abe7218b）；
  无弹窗时清空通知角——驻留错误 toast 键盘可关闭（a468a2a8）。
- 快捷键标注补齐：分页器 ←/→、展开全部 x、仅看异常芯片 b——此前仅快捷键
  帮助可查，控件悬停不可发现（e693050d）；筛选条单项移除芯片纳入键盘可达
  体系（78643de0）；18 个静态按钮补悬停说明，模板芯片静态 title 服务触屏
  与读屏（900aac09）；窄栏模式导航图标 title 补页面名（b807e33f）。

## 编辑器与表单校验对称性

- 授权编辑器输入即校验：端口格式/重叠/超时/TOTP 范围实时提示，与签发卡片
  同规则同样式，保存拦截保留双保险（2a118215）。
- 授权编辑器死配置联动：无指纹禁宽限期/无 TOTP 种子禁跳变指令，保存时按
  删除处理（57d77129）；保存前拦截开放/禁止端口重叠（RESTRICT 优先生效，
  重叠即死配置，ec9530fe）。
- 签发卡片指纹/TOFU 宽限期联动：未启用指纹时禁用 + 提示 + 提交忽略，对齐
  TOTP 范式（1b1423dd）。
- stanza 编辑器未保存修改纳入 beforeunload 守卫：刷新/关标签页不再静默丢失
  11 字段编辑现场（c5083bfe）。
- 配置快速模板新增两枚：NFQ 抓包模式（c091edc8）、SPA over HTTP 双开关
  （穿透严格出口场景，语义经 incoming_spa.c 核实，d6731f00），模板达 5 枚；
  套用后滚动定位并闪烁受影响行（2819750e）。
- 授权卡补显禁止端口/超时上限/强制真实 IP（此前仅编辑器可见），搜索纳入
  禁止端口（83c012df）。

## 时间呈现对时化与信息呈现

- 事件时间列悬停显示另一制式：相对 ↔ 含秒绝对时刻，排障对时免整表切换
  （9782895b）；最近敲门（撤销/解绑确认框两处）、审计/指标文件更新、TOFU
  状态文件、快速操作「导出审计日志」同步补绝对时刻 title（b8b211cc、7ad7e85c）。
- 事件徽章悬停显示审计英文原名：对照 JSONL 原文/工单沟通免猜译名（905bfae0）。
- 展开中的事件行左缘加强调条：inset 阴影不改背景，与异常红底/悬停色兼容
  叠加，多行展开一眼可辨（b6c53b6a）。
- 事件页副标题「刚刚刷新」改静态时间戳：fmtAgo(now) 恒为「刚刚」且不随时间
  更新，断连时成误导性陈旧信息（a7affd15）。
- 事件搜索支持 `stanza:` 前缀（授权序号或授权名直查，d384ab8a）；翻页/跳页/
  改每页条数后视口自动回落表头（0e4de267）。
- 「近 15 分钟异常」口径单点化为 countRecentBad()/BAD_WINDOW_S：标题徽标/
  侧栏/快速操作/诊断四处同源，防窗口值漂移（9864ea8f）。
- 面板非回环监听时关于页显著警示明文 HTTP 风险，诊断信息同步标注（c00f573e）。

## 主题与杂项

- 主题三态循环：跟随系统/深色/浅色，theme-color 随实际生效主题（8d4f770e）。
- 修改密码锁定按 retry_after 逐秒倒计时（对齐登录页），全选框标题明确过滤
  语义（f20bc439）。
- 响应缓存策略显式化：/api/* no-store（状态/401 响应防中间层缓存），内嵌
  HTML no-cache——升级二进制后刷新即得新 UI，从行为巧合变成契约（19814e2c）。
- CSV 导出健壮性：字段含 \r 补加引号（RFC 4180，防 Excel 断行错位），blob
  URL 延迟 5s 回收防异步下载偶发失败（e357c805）。
- toast 长文本换行防撑破、modal 限高 92vh 内部滚动（短屏兜底，18908dc6）。

## 升级说明

- 无配置/存储格式变更，直接替换二进制重启即可。
- 新端点：`POST /api/admin/qr`（重发授权 URI，2bde6186 引入；name/server
  均必填，GPG stanza 报错，与签发同级写权限 + CSRF）。
- 行为变化：/api/* 响应统一带 `Cache-Control: no-store`；内嵌 HTML 为
  no-cache。若有自建的反向代理缓存层，此变化使其失效为预期行为。
