# 2.4.6（2026-08-23）—— 批量操作与一致性打磨

2.4.5 归档后按「持续 UX 优化」循环完成的 37 项迭代汇总（每轮独立 commit，
`git log 501cd1fa..` 可逐条追溯）。

## 批量操作

- **用户页批量撤销**：授权卡片勾选框 + 顶部批量条（已选计数 / 全选当前列表 /
  取消选择 / 批量撤销），确认框列出全部待撤名称并琥珀预警其中近期有敲门
  记录的授权；逐个提交复用单撤销链路（注释禁用 + 备份 + 预检 + SIGHUP），
  部分失败 infoModal 逐条列明。
- **隐藏已选标注**：TOFU/用户两个批量条在搜索过滤后标注「含 N 条被筛选
  隐藏」+ 悬停说明，防止误操作不可见条目。

## 签发（用户页）

- 安全选项分组可折叠（点击/键盘，状态持久化）；收起后标题行实时显示生效值
  摘要（TOTP/范围/指纹/宽限/端口匹配/写入方式，宽限期 fmtSecs 人性化）。
- 签发成功结果区「再签一个」：收起结果区、滚动回顶部并聚焦名称框。
- 服务器地址历史「管理」展开芯片行，单条 × 删除（datalist 不支持逐项操作）。
- 修复：模板芯片高亮与表单实际值保持一致（手动改值/签发类似预填后偏离
  即撤下高亮与描述）；存为模板同名覆盖输入时即时预警。

## 事件页

- 排行条带第三维度「用户」（来源/设备/用户循环切换，持久化）；Top5 芯片
  追加红色 ⚠N 异常角标（BAD_EVTS 判定），悬停说明。
- 详情行「事件类型」旁放大镜一键同类筛选（与顶部类型芯片同源）。
- 「复制摘要」补齐授权名（stanza 索引反查）与 SPA 端口。
- 自定义时间区间新增「最近 24h」「昨日全天」一键填充预设。
- 异常占比条红色段悬停显示构成明细（重放 ×N…），点击直达「仅看异常」。
- 时间列相对/绝对切换键盘可达（纳入 MutationObserver + 委托机制）。

## 搜索历史通用组件

- `attachSearchHistory(input, key)`：Enter/失焦记录非空关键词（≥2 字符，
  8 条去重置顶），datalist 下拉点选；事件/用户/TOFU/配置视图/配置编辑
  五个输入框统一接入，各自独立 key 互不串扰。

## 全局与其他

- 浏览器前进/后退翻页：showPage 改 pushState + popstate 监听；配置页未保存
  修改被拦截时 hash 拨回当前页保持一致；滚动位置记忆照常生效。
- 快捷键 t 切换明暗主题（登记 ? 帮助与按钮 title）；侧栏导航悬停提示快捷键
  1-7；TOFU 排序表头键盘可达（tabindex + Enter/空格）。
- 初始化页密码实时校验：长度/两次一致性即时提示 + 强度评估（弱/中/强）。
- 通知历史导出为 .txt（遵循「仅看错误」过滤，带 BOM 与类别中文）。
- 诊断信息打包补「审计备份 N 个（体积）」与「近 15 分钟异常事件 N 条」。
- 概览：审计备份 >20 个或 >100MB 琥珀警示（含关于页合计行）；「导出审计
  日志」按钮实时标注文件大小；指标陈旧警示整行可点击直达服务控制；服务
  停止横幅内补「立即启动」按钮；方案切换对「与当前完全一致」明示。
- TOFU 表设备指纹截断 16 字符 + …（悬停见全串，复制仍取全值）；操作列
  复制改为完整 CLI 解绑命令（fwknopd-admin tofu unbind '<key>' '<dev>'）。
- 配置页两个查找框实时显示命中计数（匹配 N/M、命中 N 条）。
- 修复：首访引导条敲门命令改 `fwknop -n 凭证名称`（import 写入同名 stanza，
  client/import.c）；批量解绑成功文案改宽限期条件表述。
