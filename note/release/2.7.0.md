# 2.7.0（2026-08-24）

WebUI 持续 UX 优化第五批归档：自 2.6.0（commit `04aad70d`）起 39 项提交
（37 项功能/修复 + 1 项性能 + 1 项审计链路批查文档）。回归套件保持
**115/115 PASS**（新功能均以临时实例端到端冒烟验证：操作日志读写与轮转、
并发冲突四场景、上次登录回顾计数）。主题：**管理面可审计性与并发安全**
（面板操作日志、保存冲突防护、登录回顾）、**配置编辑器成熟化**（合并式
落盘、墓碑删除、脏实比对）、**事件排障知识库动作化**。

## 管理面可审计性与并发安全（本批最大主题）

- **面板操作日志**（612b18d2）：新增 `dashboard_ops.jsonl`（0600）——SPA
  事件有 fwknopd 审计（谁敲了门），但面板管理动作此前零持久记录。20 个
  挂点覆盖签发/撤销/重发URI/解绑/审计清理与删备份/服务控制/配置保存
  （含模式）/授权编辑（含被改指令名）/授权恢复/方案五操作/初始化/登录
  成败与锁定触发/注销/改密；detail 只含名称/指令名/规模元信息，密钥
  材料永不入档；写盘尽力而为不阻断业务。关于页新增「面板操作日志」卡
  （最近 100 条、相对时间悬停绝对、结果 ✓/✗、来源 IP、JSONL 导出端点）。
- **日志轮转 + 过滤**（5e50e5bb）：logOp 超 8MB 单代轮转 `.bak`（持续
  爆破下不再无界增长）；操作日志卡类别过滤（全部/仅看失败/账户/授权/
  配置与方案/服务与审计）——爆破刷屏时真实操作不溺水。
- **保存并发防护**（7d35e12b）：① fwknopd.conf 保存带加载时 mtime
  乐观锁——他人加载后改过的指令不再被本地合并落盘静默回滚，冲突拒绝
  后前端自动重拉配置（否则重试必再撞）；② updateStanza 打开时身份核验
  （expect_name/expect_source）——并发增删授权致序号移位时编辑不再落到
  错误的 stanza 上；均向后兼容（mtime=0/空身份跳过守卫）。
- **上次登录回顾**（5d7b2966）：GitHub 式——登录响应附带最近一次成功
  登录的时间/IP 与此后失败尝试数（先扫尾部再写本次记录），有失败时错误
  样式长驻留并引导改密+核查日志，异常访问进门第一时间可见。

## 配置编辑器成熟化

- **合并式落盘**（e93216b3）：结构化保存不再把整个文件重写为纯指令集
  （自 2.3.0 起发行版配置的大量注释在首次保存后静默丢失）——以加载时
  原文为底逐行改写：指令行替换/删除、注释/空行/%行原样保留、新增指令
  末尾追加；raw>128KB 截断时回退 lines 模式。保存确认内嵌行级 diff
  （LCS，复用方案预览 renderDiff）；零改动直返不再产生无意义备份。
- **墓碑删除**（4a49e7d2）：删除指令改软标记——红边划线置灰、输入禁用、
  再点撤销；墓碑态跨收割/重建存活，从保存口径/脏比对/校验/重复统计剔除；
  「仅看修改」纳入删除项（保存前复核终于看得见删了什么）；模板合并命中
  墓碑行撤销删除并写值；保存成功后已删行才真正移除。
- **脏标记实比对**（359bbc56）：「input 即脏」过粗——全部改回原值后
  beforeunload/折叠/切模式守卫不再误报；键计数比对防原配置含重复指令时
  打开即误脏；原文模式与打开快照同口径比对。保存成功先收割再快照，
  修复 confRows 落后 DOM 致快照失真反被误标脏。
- 重建前收割 DOM 编辑状态（0b9adf98）：删行/新增/模板合并触发重建前先
  harvest，其余行未保存输入不再被旧快照静默覆盖。
- 行级还原（f396ad4b）：ce-mod 行一键还原打开时值（Y/N 下拉同路径）。
- 空值开关行修复（c1b93147）：裸 `ENABLE_X` 行不再误标已修改、不再被
  无意改写为「ENABLE_X N」。

## 授权编辑器

- **实时改动清单**（a38aad83）：保存前「将改动 N 项」内联预览（字段
  旧→新/新增/删除，布尔人话化）——单 modal-root 不支持确认框叠加
  （会顶掉编辑器丢 11 字段现场），改为编辑过程常驻预览；口径与保存
  路径一致（死配置剥离）；全部改回原值自动复位保存按钮。

## 事件排障知识库动作化

- 排障建议内联（f66d5e5e）：6 类拒绝原因（replay/fingerprint_missing/
  not_in_whitelist/tofu_grace_expired/aged/arrived-expected）的「下一步
  怎么办」知识库直接进事件详情。
- 建议动作化（d67e69a7/fad678fc）：指纹类直达授权编辑器聚焦宽限期、

  过渡授权；stanza 已删不出死按钮。

  （同用户多授权不再混显）；授权反查统一「#序号」通道（同前缀授权名
  不再互串）。
- 徽章点击按类型筛选（15e1e08d）、授权卡「查事件」联动（c3c9d022）、
  窄屏隐藏指纹/SPA 端口两次级列（bc96ea7c，详情行完整保留）。
- 审计链路批查报告（026d181d，note/report/audit-event-coverage.md）：
  类型 8/8、reason 100% 映射核实；AUDIT_CLOSE/REJECT 零调用点定性

## 概览与引导

- __CHANGEME__ 前置（35339a98）：概览授权卡顺路累计占位密钥（零新增
  IO），转红警示直达用户页——此前要进用户页或等懒加载徽标才发现。
- 首次运行引导（9749073f）：0 授权时「三步上线」清单（校验启动 → 签发

- 零事件引导分流（c4aabb7a）：按有无生效授权区分「去签发」与排障清单。

## 可靠性与渲染修复（一批「自始未生效」级）

- **icon() 双重前缀失配**（5b22ca76）：全部 JS 生成图标自 redesign 起
  从未显示——模板芯片/复制格/警告条等图标位长期空白。
- 旧主题变量名残留（756f1751）：模板芯片/登录卡/复制格边框文字色自始
  无效；类引用批查三处残留归入样式体系（fcaa664e）。
- 全表格单元格 overflow-wrap:anywhere（47051158）：无空格长串（指纹/
  路径）不再撑破列宽。
- 初始化页密码强度指示从不显示（489e58bb）：旧版校验函数与新版绑同一
  输入写同一元素，每击键覆盖强度输出——删除旧版函数。
- 会话临期警告标志重新登录后复位（9f6e3892）：第二周期起再无提醒的
  once-flag 缺陷。
- 会话与登录限流 map 顺手清扫过期项（aeb8b30e）：长跑内存不再单调
  增长。
- 声音提示（fba96255）：异常事件蜂鸣——桌面通知的免授权补充通道。
- 配置原文一键复制（eaa76b3b）；关于页 CLI 速查表补 user qr（fc487147）；
  方案备注事后行内编辑（f740918e，新端点 POST /api/profiles/note）。

## 性能

- 审计尾读改文件偏移增量（76d4cbd2）：轮询从 O(文件大小) 降为 O(增量)，
  常态零解析；ReadBytes 手工计数——fwknopd 写入中的半行不消费，防增量
  模式永久漏事件；截断检测重建、容量扩容重建、裁头重新切片拷贝。

## 升级说明

- 纯面板升级，fwknopd 与协议无改动；替换二进制重启即可。
- 新增 `<run-dir>/dashboard_ops.jsonl`（0600）自动创建；操作日志定位
  「近期追溯」，超 8MB 单代轮转 `.bak`。
- 配置保存新增并发守卫：多人同改一份配置时后到者会被要求复核重试
  （操作日志可见是谁改的）——这不是回归，是此前静默覆盖的保护化。
