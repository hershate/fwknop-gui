# fwknop fork 2.1.0 —— 零信任硬化 + 服务端管理易用性

> 发版日期：2026-08-13
> 上游基线：fwknop 2.6.11（客户端版本号仍为 `2.6.11`，SPA 协议 `4.0.0`）
> 计划文档：[REF/plan/Port Knocking.md](../../REF/plan/Port%20Knocking.md) v2.1
> 本版本实现方案 v2.1 的阶段 2/4/6，在前版（阶段 1/3/5 + Windows 托盘）之上补齐服务端能力。

## 摘要

把 fwknop 从「专家级 CLI 工具」推进为「安装即用、可隐身、可运维」的零信任访问系统：
服务端支持动态端口范围监听、设备指纹白名单 + TOFU、TOTP 端口因子、结构化审计与指标，
并提供凭证发放闭环（`fwknopd-admin` 签发 → 客户端 `fwknop import` 即用）。

## 新增功能

### 阶段 2 —— 服务端端口范围监听
- 新增 `PCAP_PORT_RANGE` 配置：设端口范围（如 `30000-60000`）且未显式配 `PCAP_FILTER` 时，
  自动生成 `udp dst portrange START-END` BPF，使 pcap 后端监听整个 TOTP 跳变范围。
- 显式 `PCAP_FILTER` 优先；两者皆空走默认 `udp port 62201`（经典行为不变）。
- NFQ 后端：范围由 iptables `--dport START:END -j NFQUEUE` 内核过滤，无需改 fwknopd。

### 阶段 4 —— 零信任硬化 + 审计 + 服务端管理
- **4a 零信任校验**（`incoming_spa.c`）：
  - `check_device_id`：显式 `FINGERPRINT` 白名单常量时间比较；白名单空 + `REQUIRE_FINGERPRINT` 进入 **TOFU** 模式（首到 device_id 自动绑定，宽限期 `FINGERPRINT_TOFU_TIMEOUT`）。
  - `check_totp_port`：`REQUIRE_TOTP_PORT_MATCH` 用 SPA timestamp 重算应到端口，与实际到达端口比对——端口本身成为一次性因子（加密包重放到别的端口也被拒）。
  - 两道检查插在身份与端口策略之间，失配保守拒绝（不开防火墙）。
  - access.conf 新指令：`FINGERPRINT`（多行）/`REQUIRE_FINGERPRINT`/`FINGERPRINT_TOFU_TIMEOUT`/`TOTP_SEED_BASE64`/`TOTP_PORT_RANGE`/`TOTP_PORT_DIGITS`/`REQUIRE_TOTP_PORT_MATCH`，解析期强校验。
- **4b 审计与指标**（`audit.c/.h`）：8 类事件 JSON 行审计（`<run_dir>/fwknopd_audit.log`）+ Prometheus 文本指标（`<run_dir>/fwknopd.metrics`，原子重写）。新配置 `ENABLE_AUDIT`/`AUDIT_FILE`/`METRICS_FILE`（默认开）。
- **4c 服务端管理工具** `fwknopd-admin`：`user add`（生成密钥/种子/指纹 + 输出 access.conf stanza + `fwknop://` URI + QR + 加密凭证文件）、`tofu list`、`status`。凭证 JSON v1 + URL-safe base64 URI。
- **4d 客户端导入** `fwknop import`：自动识别 fwknop:// URI / 凭证 JSON（明文或加密）/ QR 图片，生成完整 rc stanza。

### 阶段 5+ —— 运维可视化（部分）
- **WebUI 运维面板**（`server/dashboard/`，Go，零外部依赖）：读阶段 4b 的审计日志 + Prometheus 指标做可视化（8 类事件计数 tile + 最近事件表 + TOFU 绑定），写操作包装 `fwknopd-admin` 签发凭证。单二进制内嵌前端（`go:embed`），默认 localhost + 只读，`-enable-write` + `DASHBOARD_TOKEN` 开管理。API：`/api/metrics`、`/api/events`、`/api/tofu`、`/api/admin/add`。
- **TUI 管理壳**（`extras/tui/fwknopd-admin-tui.sh`）：dialog/whiptail 包装 `fwknopd-admin`，服务器本机菜单（status/审计/指标/TOFU/签发凭证），无 tty 时回退纯文本菜单。
- **CLI**：`fwknop profile list` 列出 rc stanza。
- 待办（大型 greenfield）：透明自动敲门代理（iptables/nftables REDIRECT、WFP/SOCKS）、Qt 桌面 GUI。

## 已知限制
- 凭证加密用 AES-256-CBC（无内建认证）：错误口令产生乱码 → JSON 解析拒绝（干净失败，非安全缺陷）。后续可加 encrypt-then-MAC 显式检测错误口令。
- TOFU 不能阻止首用抢占（凭证被盗者先敲门），靠短宽限窗口 + 审计告警兜底。
- 阶段 5+ 的透明自动敲门代理、Qt 桌面 GUI（多周大型 greenfield）与阶段 6 的打包/迁移文档仍待办。
- WebUI/TUI 是 `fwknopd-admin` 的前端壳，写操作依赖该 CLI 在 PATH 或可定位。
