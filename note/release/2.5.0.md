# 2.5.0（2026-08-23）

WebUI 持续 UX 优化第三批归档：自 2.4.9（commit `6f3d9896`）起 45 项迭代，
回归套件维持 112 PASS。主题：预警前置（侧栏徽标体系）、键盘可达性闭环、
轮询不再打断操作、搜索语法升级、移动端录入体验。

## 预警前置：不进对应页面也能发现隐患

- 侧栏用户页琥珀徽标：仍为 `__CHANGEME__` 占位密钥的授权计数常驻，
  悬停说明后果与处置路径（462e43fa 起的授权计数卡之外的第二道提醒）。
- 侧栏 TOFU 页琥珀徽标：授权已删除/禁用的悬空绑定计数（依赖 tofu+users
  双数据源，抽 `syncNavTofuBadge()` 两侧加载后同步）。
- 概览状态卡全部可点击直达：访问授权→用户页、管理工具/审计日志/指标文件/
  写操作模式→关于页，悬停说明随状态拼接。

## 键盘可达性闭环

- `KB_CLICK_SEL` 统一体系：cp-cell 复制格、时间切换、热力柱、汇总行、
  占比异常段、分组折叠头、已禁用授权折叠头、可点击状态卡、连接条、
  服务徽标、导航徽标、会话倒计时全部纳入 Tab 序列，Enter/空格触发。
- 静态元素首扫：MutationObserver 只盯新增节点，初始 DOM 的匹配元素
  现在脚本加载后即补 tabindex（此前侧栏版本号等永远 Tab 不到）。
- 焦点保护：轮询触发的整容器 innerHTML 重建会销毁焦点元素，所有页面
  （事件/用户/TOFU/配置/方案/概览/关于）焦点在容器内时跳过重渲染，
  失焦后下一轮自动恢复；事件页新到行淡入高亮不受影响。

## 搜索与深链

- 事件深链再扩展：`~f=<类型芯片>` 与 `~t=<预设时间范围>` 入链，视图链接/
  刷新/前进后退完整还原类型筛选与时间窗（自定义时刻区间刻意不入链）。
- 事件搜索支持前缀词与裸词混用：`user:admin port:22`、`dev:abc 重放`
  等多条件 AND；此前混合查询会被当成一个子串静默零命中。
- 排行芯片新增「目标端口」维度（来源/设备/用户/端口四维循环）。
- 方案页搜索过滤（名称/备注，跨刷新记忆，接入 / 聚焦与 Esc 清空、搜索历史）。

## 配置与方案

- 配置编辑器「仅看修改」过滤：与指令名过滤叠加，保存前快速复核改动面；
  改回原值的行即时撤下，开启状态带 aria-pressed，每次打开编辑器复位。
- 配置「查看原文」模式支持按行过滤与命中高亮（查找框两模式通用）。
- 配置快速模板芯片悬浮/聚焦预览改动说明（与签发卡片模板同交互）。
- 方案列表「当前生效」置顶；方案支持「另存副本」（duplicate 端点）；
  方案名前端格式校验与服务端 profileNameRe 同源，非法名即时拦截。
- 授权编辑弹窗未修改时禁用保存，杜绝零改动备份与热加载。

## 操作反馈与防错

- 批量撤销/批量解绑/备份全部删除：按钮内实时进度（`撤销中 3/12…`）+
  执行中禁用防重。
- 「fwknopd 未运行」横幅按钮在服务操作执行中给出提示，不再静默无效。
- 表头吸附偏移顶栏高度：长表滚动时列头不再被 sticky 顶栏遮住。
- number 输入框聚焦时滚轮不再静默改值（滚动即失焦）。

## 移动端与杂项

- 技术值输入框统一 `spellcheck/autocomplete/autocapitalize=off`（23 处），
  纯数字框 `inputmode=numeric`：移动端录 IP/指纹不再被自动纠错干扰。
- 内联 SVG favicon（盾牌品牌图标，消除 /favicon.ico 404）；theme-color
  元信息随明暗主题。
- 明暗主题跨标签页即时同步（storage 事件）。
- 新到事件行一次性淡入高亮；通知历史时间悬停显绝对时间；「仅看错误」
  切换与密码可见性切换补 aria-pressed。

## 升级说明

- 无配置/存储格式变更，直接替换二进制重启即可。
- 新端点：`POST /api/profiles/duplicate`（方案另存副本，6c89b1a9 引入，
  name/target 均经 profileNameRe 校验）。
- 行为变化：事件页深链格式向后兼容（旧 `#events~bad` 链接照常可用）。
