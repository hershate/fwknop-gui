# 2.4.8（2026-08-23）—— 自助改密 + 键盘流贯通 + 可见性打磨

2.4.7 归档后按「持续 UX 优化」循环完成的 50 项迭代汇总（每轮独立 commit，
`git log 3f509492..` 可逐条追溯）。

## 账户与安全

- **关于页自助修改密码**（新端点 `POST /api/auth/password`）：需登录 + CSRF 头 +
  验证当前密码（复用登录限流桶，防会话劫持后爆破）；新密码 ≥8 位、两次一致、
  不得与旧密码相同；**改密成功即失效其余全部会话**（怀疑泄露时其他设备立即踢下线），
  当前会话保留。账户自助不受 `-read-only` 限制；Bearer-only 模式拒绝（409）。
  前端用裸 fetch 而非 api()——旧密码错误的 401 不能触发「跳回登录页」兜底。
  三框复用初始化页的强度评估/实时一致性校验/显隐眼睛/Caps Lock 警示。
- **签发结果默认掩码密钥行**：`KEY/HMAC/TOTP_SEED/GPG_PW` 各形式替换为
  `••••••••（已掩码）`，防窥屏/截图泄露；「显示敏感内容」开关可切换；复制 stanza
  仍取完整原文。
- **侧栏常驻「只读」徽章**：只读模式任何页面一眼可见（title 写明恢复方式）；
  拦截冒泡防误触「点击重连」。

## 键盘流贯通

- 用户页 `n`：直达签发（未展开先展开，名称框聚焦）；只读不响应。
- 事件页 `b`：「仅看异常」开/关。
- 方案保存表单 Enter 提交（名称/用途框）；确认框兜底不变。
- 搜索框 Esc：有内容先清空复位过滤，再按才失焦。
- 选「自定义区间」自动聚焦起始时间框；展开事件详情自动滚入视口。

## 反查与直达

- 事件详情 stanza 序号旁直接显示授权名（已删除标注 + 反查按钮禁用态）。
- 事件详情用户行「查看该用户授权」反查用户页。
- 事件详情「前后 5 分钟」上下文钻取（入钻取栈，可 ↩ 上级视图返回）。
- 解绑确认框标注绑定对应的授权（含悬空绑定三态区分）。
- 侧栏异常徽标点击直达「仅看异常」；未保存圆点点击直达配置编辑器。
- 配置视图行铅笔按钮直达编辑器并聚焦值框；配置页头部补「存为方案」入口。

## 数据可见性

- 事件 CSV 导出补「授权名称」列（懒加载解析，失败留空不阻塞导出）；缓存截断
  （≥500 条）时 toast 注明覆盖范围并引导「导出原始」。
- 审计备份列表逐文件标注备份时间与大小（`/api/overview` 的 `audit_backups`
  新增 `sizes` 逐文件字节数；时间从 `.bak-YYYYMMDD-HHMMSS` 文件名解析）。
- 已禁用授权列表补「禁用于 <时刻>」（`DisabledStanza` 新增 `disabled_at`，
  从 rm 注释前缀提取）。
- 概览「仅看异常事件」按钮实时标注异常数；通知铃铛悬停显示动态未读数。
- 「仅看异常」芯片悬停说明异常判定构成（reject/replay/unknown_fingerprint/
  port_mismatch/aged）。

## 校验与提示

- 配置编辑器 `ENABLE_*`/`FLUSH_*`/`EXIT_*` 开关指令值 Y/N 校验（注释如实说明
  服务端 `strncasecmp(v,"Y",1)` 判定语义，未编造「预检拒绝」）；指令名改动时
  行内说明即时刷新。
- 签发服务器地址留空：编辑时即时提示 + 签发成功后 toast 双提示 URI 主机为
  占位符「server」（与 credential_to_uri 实际行为核实一致）。
- 「允许访问端口」留空提示服务端默认 tcp/22；TOFU 状态文件不存在时说明创建时机。
- 登录页补「忘记密码」重置指引（删 dashboard_auth.json 重初始化）。
- 事件/TOFU 表头列语义悬停；服务控制六按钮悬停说明；概览管理工具/服务进程/
  指标文件/写操作模式卡悬停排查指引。
