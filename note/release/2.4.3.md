# 2.4.3（2026-08-23）—— 一键签发即生效 + 体验持续打磨

2.4.2 归档后按「持续 UX 优化」循环完成的 49 项迭代汇总（每轮独立 commit，
`git log ee3adf3c..HEAD` 可逐条追溯）。

## 签发（用户页）

- **一键签发即生效**：新增「签发后写入 access.conf 并热加载」复选框
  （默认开启，入草稿）。服务端 `extractPrintedStanza` 截取 `user add`
  输出中的 stanza 段，`appendStanza` 复用既有安全流程：启用/禁用同名
  查重 → fwknopd 预检 → 备份 → 原子替换 → SIGHUP 热加载。写入失败不
  影响签发结果，原始 stanza 仍可从输出复制手动追加。
- **访问超时可自定义**：`fwknopd-admin user add --fw-timeout S`
  （1-8388608，与 access.c `RCHK_MAX_FW_TIMEOUT` 一致，越界拒绝），
  面板字段带分钟/小时换算即时校验，入草稿与提交前汇总校验。
- **自定义签发模板**：「＋ 存为模板」抓取当前安全选项（含 fw-timeout）
  与名称/描述，localStorage 持久化；自定义芯片与预制模板同一交互
  （点击填充、hover 预览、active 高亮、草稿记录、× 删除需确认）。
- TOTP 关闭时联动禁用「端口范围」「强制端口匹配」（灰化 + 提示 +
  提交时忽略残留值），覆盖开关切换/模板应用/草稿恢复/签发重置全路径。
- OPEN_PORTS 常用端口快捷芯片（SSH/HTTPS/HTTP/DNS/OpenVPN/RDP，点击
  切换含/不含，已含高亮并与手动输入双向同步）。
- 要求用户名字段 Unix 惯例即时校验（空白/长度硬约束 + 小写惯例警告）。
- 名称重名（含已禁用同名）时自动建议可用变体（name-2…），点击即填。
- 签发成功结果区新增「查看该授权」直达（跳用户页按名筛选定位）。

## SPA 事件页

- 筛选状态（搜索词/类型芯片/时间范围/自定义区间）持久化，刷新后恢复
  排查现场；一键重置联动清除。

- 说明列点击按原因筛选；详情行端口补齐点击筛选（与主行一致）。
- 详情行新增两个反查：stanza 索引 → 用户页该授权；设备指纹 → TOFU
  页绑定状态。

## 全局与框架

- 模态框关闭后焦点返还触发元素（isConnected 守卫）；confirmDialog 统一
  走 openModal/closeModal，消除两套模态实现漂移。
- 键盘快捷键帮助面板：按 ? 或侧栏按钮打开；关于页快捷键表改由同一
  KBD_HELP 数据源渲染（修复静态副本漂移）。
- 侧栏：事件导航项显示 15 分钟异常徽标（当前在事件页则隐藏）；配置
  导航项显示未保存修改圆点；底部常驻版本号（服务端下发，硬编码仅
  作首屏占位）。
- 顶栏：自动刷新倒计时（距下次刷新 Ns，断连/后台/关闭时隐藏）；
  小屏（≤640px）隐藏文字标签精简空间。
- 浏览器标签页标题携带当前页面名（`(N 异常) 页面名 · fwknop 运维面板`）。
- 通知历史持久化到 sessionStorage（刷新可追溯，关标签即清）。
- toast 悬停暂停消失倒计时（移开 2s 兜底）；驻留型错误 toast 不受影响。
- 写操作 HTTP 失败自动 toast 服务端错误文本（此前大量 catch 静默吞掉）；
  GET 轮询失败仍由断连指示统一表达。
- 注销前有未保存配置修改时弹确认（与离开拦截、导航圆点构成防丢链路）。
- 登录/初始化密码框 Caps Lock 开启警示（按 id 绑定，显隐切换不失效）。
- 关于页新增常用命令速查卡（客户端导入/fwknopd-admin/预检，可复制，
  命令语法与 usage() 逐一核对）。
