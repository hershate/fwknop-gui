# 2.4.7（2026-08-23）—— 跨配置一致性校验 + 反查闭环 + 可访问性补齐

2.4.6 归档后按「持续 UX 优化」循环完成的 24 项迭代汇总（每轮独立 commit，
`git log 93223d3c..` 可逐条追溯）。

## 跨配置一致性（PCAP_PORT_RANGE × TOTP_PORT_RANGE）

- **stanza 编辑器保存前拦截**：在线编辑 TOTP_PORT_RANGE 超出服务端监听范围时
  阻止落盘（与签发卡片共用 rangePcapConflict；配置未加载先懒加载），字段 tip
  补「须落在 PCAP_PORT_RANGE 内」说明。
- **保存 fwknopd.conf 反向校验**：收窄监听范围会使现有授权的 TOTP 范围越界
  （敲门静默丢失），确认框内琥珀列出受影响授权及范围，确认后才继续。
- **语义澄清**：签发卡片「允许访问端口」（敲门后放行的服务端口）与「TOTP
  端口范围」（敲门包目的端口/跳变落点）互相指引；事件详情两个端口字段
  悬停即见解释。

## 反查闭环与定位

- **事件详情反查按钮禁用态**：stanza/TOFU 数据已加载且目标不存在时按钮禁用
  并给出原因，不再点了扑空；stanza 反查在 S.users 未加载时先懒加载，修复
  误报「该 stanza 已不存在」；查找统一按 index 字段。
- **TOFU 绑定行内反查授权**：来源限制列补「查看授权」按钮，按 stanza_key
  找回 stanza 直达用户页过滤定位；无名授权搜索词回退用户名/来源；与悬空
  标记互斥。
- **用户页搜索支持 stanza 序号直查**（「3」或「#3」，占位文案同步）；
  stanza 反查遇无名授权回退按「#N」过滤。
- **未写入配置时一键复制 stanza 段**：「尚未写入 access.conf」提示条内按钮，
  按服务端 extractPrintedStanza 同规则截取输出，手动落盘路径闭环。

## 通知与全局感知

- 标签页标题补未读通知计数：`(N 异常) [M 通知] 页面 · fwknop 运维面板`，
  后台标签可感知；入档/已读清零同步刷新。
- 通知历史「新」条目标记（已读水位 S.notifReadTs，弹窗内重渲染稳定）。
- toast 正文点击即复制（报错文本贴工单不用手选；关闭语义不变）。
- 概览快速操作补「复制诊断信息」（诊断逻辑提取为 collectDiag()，与关于页
  同一数据源）。
- **时钟偏差警示提到概览顶部**：TOTP 严格依赖时钟一致，偏差 >60s 开门即见
  （此前仅关于页），附偏差方向与 NTP 建议。

## 可访问性

- 事件时间分布柱键盘可达（有事件的柱块 evh-hot + role/aria-label，纳入
  MutationObserver 补 tabindex 与 Enter/空格委托；空柱不进 Tab 序列）。
- 主题切换按钮 aria-pressed 同步；侧栏当前页 aria-current="page"。

## 事件页与杂项

- 副标题显示筛选匹配数（「匹配 N 条」前缀，主题色）。
- 「筛选中」时间标签显示自定义区间具体起止（区间 08-23 10:00 ~ 11:00）。
- 自定义区间起止倒挂自动交换并 toast 说明（不再静默筛出 0 条）。
- 方案预览/切换确认补 access.conf 差异对比（/api/profiles/view 新增
  current_access_conf，密钥同规则掩码）；「完全一致」判定改为两个文件
  都一致才算。
- 方案卡片补相对时间（保存于 …（3 天前））；签发草稿恢复条显示保存时间。
- 计数卡趋势图采样不足时占位提示「趋势采样中…」，不误读为「无流量」。
- 修复：TOFU 批量选择集剔除失效绑定（单台解绑后计数不再虚高）。
