# fwknop fork 2.3.0 —— WebUI 全功能化：服务控制 / 配置编辑 / 方案切换

> 发版日期：2026-08-23
> 上游基线：fwknop 2.6.11（客户端版本号仍为 `2.6.11`，SPA 协议 `4.0.0`）
> 本版本把服务端 WebUI 从「监控 + 签发」推进为**覆盖 fwknopd 全生命周期**的
> 管理面板：服务启停、可视化配置编辑、配置方案一键切换。

## 新增功能

### 服务控制（概览页）
- **启动 / 停止 / 重启 / 热加载（SIGHUP）**：启动与重启前强制执行
  `fwknopd --exit-parse-config` 配置预检，预检不过拒绝启动；停止为 SIGTERM +
  等待退出；所有操作二次确认并展示原始输出。
- **校验配置**按钮：不改动任何东西的预检（`validate`）。
- **防火墙规则**查看：包装 `fwknopd --fw-list`（无 root 时优雅降级提示）。
- 顶栏与概览显示：进程存活（PID 文件 + signal 0 探测）、PID、启动时间。
- 新参数：`-fwknopd`（fwknopd 二进制路径，默认从 PATH 查找）。

### 可视化配置编辑（服务配置页，写模式）
- **fwknopd.conf 结构化编辑器**：指令逐行增/改/删，Y/N 类指令自动渲染为开关，
  指令名自动补全（datalist），常用指令中文说明随行显示；另有**原文编辑**模式。
- **保存流水线**：写入临时文件 → `fwknopd --exit-parse-config` 预检 →
  备份原文件（`.bak-<时间戳>`）→ 原子替换 → SIGHUP 热加载。预检失败**不落盘**。
- **access.conf stanza 在线编辑**（用户与授权页）：11 个非密钥指令的模态表单
  （SOURCE/用户名/开放与禁止端口/超时/强制真实 IP/TOTP 范围/指纹与端口因子开关/
  TOFU 宽限期）。**密钥行永不进入浏览器**，编辑时原样保留；预检 + 备份 + 热加载。
- **撤销恢复**：被 `user rm` 注释禁用的授权在列表下方单独分区，可一键恢复
  （还原注释 + 预检 + 备份 + 热加载）。

### 配置方案（新页面，一键切换）
- **保存方案**：当前 fwknopd.conf + access.conf 快照为命名方案（带备注与时间）。
- **预览**：方案内容查看（access.conf 密钥一律掩码）。
- **应用**：先校验方案自身配置 → 备份当前双文件 → 替换 → 热加载；失败即中止，
  当前配置不受影响（可回滚）。
- **删除**：仅删快照。方案名严格校验（防路径穿越）。
- 存放目录：`-profile-dir`（默认 `<run-dir>/profiles/<名称>/`）。

### 其他
- SPA 事件页：**审计日志导出**（JSONL 下载）。
- 写操作门禁：只读模式下面板自动隐藏/禁用全部管理控件（签发表单、服务按钮、
  编辑器、方案保存），并给出如何启用写模式的提示。
- 「关于」页安全说明同步更新。

## 新增 API

| 端点 | 方法 | 说明 |
| --- | --- | --- |
| `/api/service/validate` | POST | 配置预检（fwknopd --exit-parse-config） |
| `/api/service/start` `stop` `restart` `reload` | POST | 服务控制 |
| `/api/service/fwrules` | GET | `fwknopd --fw-list` 输出 |
| `/api/config/fwknopd` | POST | 保存 fwknopd.conf（structured / raw） |
| `/api/config/stanza` | POST | 编辑 stanza 非密钥指令 |
| `/api/config/stanza/enable` | POST | 恢复被禁用的授权 |
| `/api/profiles` | GET | 方案列表 |
| `/api/profiles/view` | GET | 方案预览（密钥掩码） |
| `/api/profiles/save` `apply` `delete` | POST | 方案管理 |
| `/api/audit/download` | GET | 审计日志下载 |

## 安全边界（刻意保留）

- 面板与 API 任何路径都**不输出密钥原文**；stanza 编辑拒绝密钥字段（服务端强校验）。
- 所有写操作需 `-enable-write` + `DASHBOARD_TOKEN`（Bearer）。
- 全部外部命令用参数数组执行（无 shell）；方案名白名单正则校验。
- 所有配置落盘：预检 → 备份 → 原子替换；服务启动/重启强制预检。

## 已知限制

- 服务控制依赖 PID 文件（`-pid-file` 需与 fwknopd 实际一致）；systemd unit 管理
  （enable/disable）不在面板范围内。
- `--fw-list` 需面板进程有权限读取防火墙规则（通常需 root）。
- fwknopd 预检对「未知指令」只告警不报错（上游行为），拼写错误主要靠
  结构化编辑器的指令补全规避。
