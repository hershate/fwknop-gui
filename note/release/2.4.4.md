# 2.4.4（2026-08-23）—— 可访问性补齐 + 失败态兜底 + 效率微交互

2.4.3 归档后按「持续 UX 优化」循环完成的 27 项迭代汇总（每轮独立 commit，
`git log b9b2140b..48a29310` 可逐条追溯）。

## 无障碍与键盘可达

- 概览计数卡、摘要卡键盘可达（tabindex + role=button + Enter/空格触发 +
  focus-visible 聚焦样式），此前仅鼠标可点。
- cp-cell 点击复制/筛选单元格全局键盘可达：MutationObserver 自动补
  tabindex，Enter/空格事件委托，动态渲染的内容同样生效。
- aria-live 补齐 5 处动态区域（模板描述/签发结果/新事件条/会话倒计时/
  连接状态），读屏用户可感知异步变化。
- 全局 `window error` 兜底 toast：界面脚本异常不再静默，用户可见可反馈。

## SPA 事件页

- 事件详情新增「复制摘要」：一行中文可读文本（时间/类型/来源/用户/端口/
  原因），贴工单、发消息即用。
- 异常事件桌面通知：可选开启（Notification API），标签页在后台时新异常
  弹系统通知，同 tag 覆盖防刷屏，开关状态持久化。
- 事件表密度切换：紧凑/舒适两档，紧凑模式一屏看更多事件，选择持久化。
- 「筛选中」标签条：当前生效的每项筛选以标签呈现，逐项 ✕ 拆卸、一键
  全部清除，筛选状态始终可见。
- 事件详情支持直接解绑已绑定设备（与 TOFU 表共用 unbindDevice）。

## TOFU

- TOFU 表行密度切换，与事件表同一交互；密度逻辑抽为公共函数
  `initDensityToggle`，两表独立持久化。

## 配置与方案

- 配置页新增「展开全部 / 收起全部」分组按钮。
- 视图模式指令查找框：按键名/说明过滤行，命中分组自动展开，清空恢复
  原折叠状态，轮询重渲染后查找词保持（此前过滤框仅编辑模式可用）。
- 原文编辑模式显示行数/字符数统计。
- 配置方案一键时间戳命名（conf-YYYYMMDD-HHMM，重名自动 -2/-3）。

## 签发（用户页）

- 访问超时常用值芯片（30 秒/5 分钟/1 小时/1 天）。
- TOFU 宽限常用值芯片（1h/1d/7d/仅本机清空）。
- TOTP 端口范围常用值芯片（30000-60000 / 40000-50000 / 10000-65000）。
- apply 关闭签发时结果区驻留「未写入配置」提示条，防止误以为已生效。

## 登录与全局

- 登录失败提示剩余尝试次数（「再失败 N 次将锁定 60 秒」），锁定不再
  突然；服务端 401 文案升级，`recordLoginFail` 返回剩余次数。
- 侧栏连接状态区点击立即重连刷新。
- 加载失败兜底：首屏骨架屏不再无限挂着——失败时替换为「加载失败 +
  立即重试」占位（9 个容器全覆盖，tbody 自动包行），已有内容保留可读。
- 通知历史「仅看错误」过滤 + 单条点击复制消息文本。
- 打印/导出 PDF 样式：隐藏交互控件，事件详情展开项一并打印。
- 品牌区版本号动态化（与侧栏同源，硬编码仅作首屏占位）。
- 移除未引用的 svc-output 死元素。

## 测试

- fork 回归 **90/90 PASS**：新增登录失败剩余次数提示用例
  （python3 urllib 读取 401 响应体，wget 对 401 不输出 body）。

## 升级说明

- 无破坏性变更；`/api/login` 仅 401 文案变化（增加剩余次数信息），
  状态码与限流策略不变。其余全部为前端交互层改动。
